# 声场国内服务器购买与上线说明

## 先买什么

- 云厂商：阿里云或腾讯云，域名与服务器放在同一厂商便于办理备案和管理。
- 产品：轻量应用服务器，2 核 2G 起步，系统选 Ubuntu 24.04 LTS（纯系统镜像），建议 SSD 40GB 或更高。
- 地区：优先考虑北京/华北，方便大连用户访问。
- 网络：确保包含可访问的公网 IPv4；带宽 3–5 Mbps 可作小范围公测起点，具体套餐和流量限制购买时确认。
- 备案：购买前确认该套餐支持 ICP 备案，满足该云厂商要求的购买时长、资源资格及主体要求。不要仅凭低价购买无法备案的套餐。
- 域名：选择容易输入的名称；价格及续费以购买页为准。大陆服务器绑定域名提供网站通常需要先完成 ICP 备案，审核周期以云厂商及主管部门为准。

请在云厂商官网自行付款，不需要在聊天里发送账号密码。购买后提供云厂商、系统版本、公网 IP、域名；远程连接方式另行配置。

## 部署包内容

已准备 Dockerfile、compose.yaml、Caddyfile 和 .env.example。应用与网页共用一个域名，Caddy 提供自动 HTTPS，账号数据库通过数据卷持久化。AI Key 可留空。

本机已验证前端构建、正式模式网页与题库查询、账号鉴权及账号生命周期。尚未在 Linux 服务器验证 Docker 构建、证书签发或备案后的公网访问。

## 买好后的上线顺序

1. 完成域名实名认证和备案所需资料，按云厂商流程办理。
2. 配置服务器远程连接，并安装 Docker Engine 与 Compose 插件。
3. 上传并解压部署包，进入包含 compose.yaml 的目录。
4. 复制 .env.example 为 .env，将 DOMAIN 改为实际使用的域名，例如 music.你的域名；不用填写 https://。
5. 备案及接入流程完成后，将该域名的 A 记录解析到服务器公网 IPv4。
6. 云安全组与服务器防火墙允许 TCP 80、443；SSH 管理端口尽量仅对管理者 IP 开放。3000 端口由容器内部使用，无需公网放行。
7. 在部署目录运行 `docker compose up -d --build`。Caddy 在域名已正确解析、80/443 可达时申请证书。
8. 用 `docker compose ps` 和 `docker compose logs --tail=100` 检查启动状态，再访问 https://实际域名。
9. 验证注册登录、改密、刷题、听音及服务重启后的账号持久化。
10. 网站页脚按备案要求展示备案号和官方查询链接，随后按要求办理公安联网备案等事项。

## 数据与版本范围

账号数据库使用 SQLite，适合当前单机小范围公测。实际账号在容器数据卷中，删除数据卷会丢失账号；不要执行 `docker compose down -v`。备份和迁移由部署时一并配置。默认部署包不包含本机账号、真实密码、API Key 或数据库。

当前站点包含账号密码系统、1000 道乐理题、基础解析和听音 UI。练习记录与错题仍保存在用户浏览器，排行榜仍为示例，判题也尚未迁移到后端。可先用于体验评审，正式竞技排名需继续完成服务端答题记录及判题。
