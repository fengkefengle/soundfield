# 乐理题库导入说明

来源：乐理练习题库_1000题含答案.docx。

已转换并导入 1000 道四选一题，每类 200 道；每题保留原文题号、原题和参考答案，配有基础解析。按去除空白并合并是什么/构成什么的文本规则检查，未发现重复题；并非全面语义去重。

## 使用方式

打开 http://127.0.0.1:5173/ ，登录后进入乐理刷题，选择分类。每类题号 1–200 对应原文，可通过题号跳转核对。点击答案即可判题，答错自动进入错题本。旧版示例题的错题仍可复习。

## 验证

1000 道均有四个不同选项、有效答案位置和解析；五类题号均覆盖 1–200。已检查谱表位置、三连音时值、钢琴音域、和弦音名拼写和关键修正案例。音程、和弦与主要音阶题使用规则重新核算。答案位置 A/B/C/D 各 250 道。

## 当前产品范围

题库已用于当前 UI 练习，后端查询接口同步更新。练习判题目前仍在前端，正式竞争排行榜上线前需迁移到服务端判题。账号保存在数据库，答题和错题仍为当前浏览器按账号保存。
