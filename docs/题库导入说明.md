# 乐理题库导入说明

新版来源：用户提供的《乐理练习题库_五类各3000题_含答案.docx》。

已将全部 15000 道题转换为四选一，音程、和弦、调式、节奏、记谱法各 3000 道，每题配基础解析并保留分类内原题号。新版 ID 为 20001–35000；旧版 1000 题保留原 ID 用于历史错题复习，避免旧记录对应到新题。

## 使用

登录后进入乐理刷题，选择分类，输入 1–3000 跳转题号。答题后即时反馈，点击“求解析”查看基础讲解。DeepSeek 接口可选配，无密钥也能使用基础解析。

## 核对

按规则核算音程度数、半音数、转位、音名拼写、和弦结构、调式音阶、谱表位置与时值。共 3418 条答案文本调整、8162 条题干澄清；包含格式、精度、科学音高记号、题意限定及错误纠正，不代表所有调整都是原答案错误。未调用 AI。

| 示例 | 处理 |
| --- | --- |
| D—A 是几度 | D E F G A 共五度 |
| G♭—B | 跨三度、五半音，为增三度 |
| F♯ 大调关系小调 | d♯ 小调 |
| f 自然小调关系大调 | A♭ 大调 |
| 低音第二线与下加一间 | B2 与 F2，相差四度 |
| 双附点三十二分音符 | 四分音符为一拍时为 0.21875 拍 |

无八度的双音题按前音向上至后音的简单音程理解。和弦转位题明确从低到高排列，等音按叠三度拼写修正。旋律小调明确上行，自然小调第七级称下主音。七声宫/商调式明确给定音为主音。大调完整下行八度从上方主音开始。谱表题使用科学音高记号（C4 为中央 C），复音程度数按绝对线间距离计算。复拍子算时明确速度按分母音符计数，避免与指挥大拍混淆。

## 验证与边界

全部题目通过 ID 唯一、每类数量、四个非重复选项、有效答案索引和非空解析检查。题干去除空白后有 15000 个不同文本；未做全面语义去重。规则回归检查覆盖音程、关系调、谱表位置及精确时值。干扰项按规则生成，建议公测时由乐理老师抽查。

完整原题、原答案、调整后答案和原因保留在本地输出“新增15000题核对记录.json”。原始 Word 和账号数据库不上传。新版题库按五类分成独立文件与构建资源，首次打开仍需加载题库；服务器 gzip 可减少传输量。练习记录与错题仍按账号保存在浏览器，尚未跨设备同步。
